# Expense Tracker

A Flask-based web application that allows users to track income and expenses through a simple web interface.

## Features

- Record monthly income
- Add and categorise expenses
- View spending by category
- Calculate remaining budget
- Responsive user interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
